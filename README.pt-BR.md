### Sobre mim

- **Full-stack:** entrego aplicações da API à interface com **Node.js, NestJS, Go, React e Next.js**, além de **React Native** no mobile. Clean Architecture, SOLID e design patterns para manter o código testável conforme cresce.
- **DevOps e observabilidade:** stacks containerizadas com **Docker**, CI/CD com **GitHub Actions**, métricas e alertas com **Prometheus, Grafana e Alertmanager**. Me importo com sistemas que degradam graciosamente, contratos de API claros e saber o que acontece em produção.
- **Segurança:** certificado **Google Cybersecurity**. Estudando Linux, redes e computação forense (cadeia de custódia, aquisição de evidências, antiforense).
- **IA em produtos:** uso o **Google Gemini** para transformar material de estudo em quizzes e para auditar requisitos de software em busca de ambiguidades.
- **Projetos para clientes:** sites e plataformas para negócios reais, incluindo migrações de WordPress para React e e-commerce de marca.
