### About

- **Full-stack builder:** ship web apps from API to UI with **Node.js, NestJS, Go, React and Next.js**, plus **React Native** for mobile. Clean Architecture, SOLID and design patterns to keep codebases testable as they grow.
- **DevOps & observability:** containerized stacks with **Docker**, CI/CD with **GitHub Actions**, metrics and alerting with **Prometheus, Grafana and Alertmanager**. I care about systems that degrade gracefully, clear API contracts and knowing what's happening in production.
- **Security:** **Google Cybersecurity** certified. Studying Linux, networking and digital forensics (chain of custody, evidence acquisition, anti-forensics).
- **AI in products:** using **Google Gemini** to turn study material into quizzes and to audit software requirements for ambiguity.
- **Client work:** delivering sites and platforms for real businesses, including WordPress-to-React migrations and brand e-commerce.
